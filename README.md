# study-spot-finder

Study Spot Finder is a web application that helps students find a good place to study at SFU and around Vancouver. Students often waste time looking for a spot that is quiet, has outlets, and has free seats, especially during midterms and finals, and they can’t tell what a place is like until they get there. Right now they rely on word of mouth, group chats, or Google Maps. Google Maps reviews are written for general customers and rarely mention noise or outlets, and the SFU Library website only covers its own spaces. No existing tool combines a map, study-specific details, and student reviews for SFU and Vancouver.
Our app saves students time and helps them find a space that suits their needs, including accessibility needs. It is practical and educational rather than entertainment. The target audience is university students, mainly at SFU’s campuses and others around Vancouver, and anyone who needs a place to study.
The project has five epics, one for each group member. The first is an interactive map that uses a web API to find and show locations. The second is user profiles and reviews. The third is accessibility and attributes such as noise level, outlets, and parking. The fourth is tags and filtering by SFU campus or city. The fifth is an admin system for managing locations and reviews. A secondary feature, chats and connections between users, will be added if time allows. With five main epics, each member has one major feature, so the workload is enough for five people.
